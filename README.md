# Disable Keyboard Shortcuts - a Firefox extension

You know how some websites have custom keyboard shortcuts that override those of your browser (looking at you Notion.so)? Well there are two ways of dealing with it.

1. Go into Firefox's settings and globally disable keyboard shortcuts.
2. Install this extension and toggle keyboard shortcuts on and off.

Obviously option #2 is the best. It's important to note that built-in Firefox shortcuts (like CMD + 1, or whatever) remain intact. It's just the custom ones that web developers implement to make their website feel more like a native app.

## In alpha

This whole project is in it's super early stages. As such, I'm not gonna tell you how to install it. This is so people don't fuck up their browser unintentionally. However, if you know how to install custom Firefox extensions that haven't gone through the Firefox Extension Store, feel free to give this a go.
